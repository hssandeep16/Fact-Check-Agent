# Fact-Check-Agent
A tool that takes an AI-written paragraph and searches Google/Wikipedia to see if it's actually true.

The Mission: A tool that takes an AI-written paragraph and searches Google/Wikipedia to see if it's actually true.

The Fact: In 2026, 70% of web traffic is AI-generated, but only 20% is actually accurate. Being the "Auditor" is the new gold mine.

Simple Logic: Text -> AI Extraction of Claims -> Search API -> Green/Red Light Report.
